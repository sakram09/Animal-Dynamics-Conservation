 Project 2: Animal Conservation (Computer Vision / Deep Learning)1. Data Kahan Se Liya Aur Sample Size Kya Tha?Asal Source: Wildlife camera traps ka data, jaise Kaggle ka Snapshot Serengeti dataset.Sample Size: Total 200 images ($224 \times 224$ pixels, RGB channels) use kiye.Classes: Do categories thi—Healthy Wildlife aur Injured/Malnourished Wildlife.2. Data Ke Saath Pehle Kya Kiya? (Preprocessing & Augmentation)Data ko 80/20 split kiya (160 images training aur 40 images testing ke liye).Camera traps mein images hamesha limited hoti hain aur angles kharab hote hain, isliye humne Data Augmentation (ImageDataGenerator) lagaya. Images ko randomly rotate kiya, flip kiya, aur zoom kiya taake model real-world wild environment ke liye train ho aur overfit na ho.Pixel values ko 0-255 se scale karke 1./255 (0 aur 1 ke beech) par normalize kiya.3. Model Kaunsa Use Kiya Aur Kyun?Model: MobileNetV2 (Transfer Learning approach).Kyun Kiya: Kyun ke hamare paas millions of animal images nahi thi. MobileNetV2 pehle se ImageNet par trained hai, usko basic shapes aur edges pehle se pata hain. Dusra faida ye hai ke ye lightweight hai aur forest camera traps jaisi edge devices par aaram se chal jata hai.Humne MobileNet ke bottom layers ko freeze rakha aur top par apni custom dense layer ($128$ units with ReLU) aur ek 40% Dropout layer lagayi (taake model neurons ko randomly drop karke generalizability badhaye). Output ke liye Sigmoid activation use kiya (Binary classification).4. Accuracy Aur Validation Kaise Hui?Model ko 5 epochs tak train kiya. Loss function binary_crossentropy aur optimizer Adam use kiya.Model ne test set (40 untouched images) par predict kiya aur unka Seaborn Heatmap Confusion Matrix image generate kiya jo saaf dikhata hai ke kitne healthy aur injured animals sahi predict hue.Aakhir mein pure deep learning model architecture aur weights ko .h5 file format mein save kar liya taake instant inference ke liye reload kiya ja sake.
